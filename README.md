# Tamara

tamara.co 1:1 clone — full ar-sa + en-sa, Next.js + Webflow runtime, verbatim markup

[Source](https://github.com/Up-to-code/tamara) · [Issues](https://github.com/Up-to-code/tamara/issues) · [Project directory](https://github.com/qentrah/.github/blob/main/profile/PROJECTS.md)

## Technology

Next.js, React, TypeScript.

## Get started

```sh
git clone https://github.com/Up-to-code/tamara.git
cd tamara
```

Requires Node.js and npm.

```sh
npm ci
npm run dev
```

## Available commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Development server |
| `npm run start` | Start the configured application |
| `npm run build` | Build the project |
| `npm run typecheck` | Check types |
